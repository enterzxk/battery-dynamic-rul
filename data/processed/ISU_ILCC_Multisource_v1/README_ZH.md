# ISU-ILCC 多源因果特征资产 v1

本资产由原始 RPT_json/Cycling_json 的训练与开发电芯生成。188 个电芯包括 C1/C2 训练 125 个、C3 开发 63 个；C4 原始数据和预测轨迹均未读取。C 是同一 G 工况组内的电芯编号，不代表新的工况。

入口是本目录的 asset_manifest.json。它引用服务器上不可覆盖的源特征文件及其清单哈希，不复制或移动已冻结的文件。原始压缩分段缓存继续保留，可用于有授权的后续提取。

RPT 资产含 4,108 个合法 RPT 的 204 个数值：四项实测充放电容量，以及四条倍率/充放电曲线的 Q(V)、dQ/dV(V) 固定电压采样。这里历史字段 C2/C_2 表示 **C/2，即0.5C**；C5/C_5 表示 **C/5，即0.2C**，不可误读成2C和5C。原始特征单位分别为 Ah、Ah/V，电压网格为3.00–4.20 V。缺少观测支持的点保持缺失，不外推。

Cycling 资产含1,248,949条原始循环记录，压缩特征共316,628,346字节。保留每个源循环及两条充放电腿的实际时钟、容量与Q/V/I/E统计，原始字段单位为Ah、V、A、Wh。没有导出的温度、松弛或阻抗数值不会被伪造。官方实验确有部分工况的pulse/DCIR测试，但当前JSON资产没有单独提取这些信号；两者不能混为一谈。

完成解码与CRC校验不代表每条记录都具有合法在线时钟。正式预处理发现源记录将部分缺失时间写成字符串`[]`。这些记录保留在原始派生资产中；合并两条腿的模型特征要求两条stop都能解释为真实ISO时间，未知或损坏时钟的循环不进入任何as-of索引，排除数量和源索引仅作审计元数据。缺失start只使对应duration不可用。禁止为缺口插值、用源循环索引推算时间，或把全电芯的缺失数量输入某个过去查询。

无时区源时间采用与冻结V18一致的UTC坐标解释，以保证数值对齐；这不代表已测得仪器实际时区。源时间结束与通信到达时间分开记录。RPT按实验臂施加完整报告、隔次报告或7天延迟；每项容量和曲线同时满足stop≤arrival≤query才可见。Cycling通信延迟未测量，当前“完成即可见”是明确的实验假设。

常规循环容量受到工况/SOC窗口影响，不能当成与完整C/5 RPT等价的容量检查。累计吞吐量只累计有合法时钟、两条腿容量都可用的源循环。observed EFC可以定义为该双腿Ah总和除以2×0.25Ah；它排除未观测缺口和未计入的RPT，不等于native cycle数或完整实际EFC。

查询特征由experiments/multisource_factorial_20261021/features.py构建。正式F0/F1/F2/F3是RPT增量和Cycling增量的2×2对照。查询时的RPT容量量纲除以0.25Ah，归一化后的dQ/dV量纲为1/V；形状控制则除以同一记录同一倍率/充放电腿的实测容量。latest、相对首次可见检查的变化、过去斜率均只用已到达的RPT。

合法RUL目标仍为原始有效RPT首次测得容量≤0.20Ah的stop时间，单位为周。报告被隐藏或延迟不改变这个源事件。它不等于潜在物理首次越阈时间；源记录没有出现事件的未来寿命保持未知。

本目录提供可复用资产入口与算法链接。特征清单、原始派生数值和完整逐查询预测留在服务器；GitHub白名单仅同步代码、清单、协议和经过审查的研究结果，不公开原始信号或权重。
