# 中文总研究计划 v0.1
研究问题：仅使用截至查询循环可观察的充放电与工况历史，预测不同电芯及异构老化条件下的剩余循环寿命，评价泛化、负迁移、更新稳定性和危险高估。论文目标以真实创新和证据为先，TSC适配须另行判断。

|阶段|工作与交付|放行条件|
|---|---|---|
|G0|环境、模型、网络、版本、任务锁、调度与恢复实测|自动化已验证能力和限制明确|
|G1|10批约5篇真实文献；矩阵、正文方法/实验/消融/限制、独立审查|约50篇代表性论文，全文优先；不足不凑数|
|G2|官方BatteryLife/PBT代码与MATR/HUST数据、标签、EOL、划分、许可审计|真实物理电芯映射、输入可见性、预训练重叠可追溯|
|G3|CPMLP、CPTransformer、PBT官方任务忠实复现|配置/版本/预测/日志/种子/预算完整，差异明确|
|G4|统一动态RUL多前缀基准，未知工况与跨数据集|train/validation/calibration/test隔离，冻结查询和公平预算|
|G5|早期信息不足、域外下降、负迁移、震荡和危险高估诊断|真实对照、聚类置信区间与反例|
|G6|2–3个可反驳假说、已有工作冲突、机制/消融/预算公平|允许无增益或停止，不强行提创新|
|G7|实验与论文整合，独立评审，TSC适配|无虚构；可编辑图表与复现包|

G1期间同步准备代码和数据契约；不在标签/划分审计前启动训练。阶段完成以文件证据和独立审核为准。

文献配额建议：基础与经典8；BatteryLife/BatteryML/BatLiNet/PBT及基准8；动态RUL/轨迹/迁移12；自监督/预训练/序列模型8；不确定性/校准/负迁移9；健康服务/计算管理5。同一论文只计一次，2024–2026优先，保留必要经典。正式出版与预印本年份分列，材料日期不能晚于实际检索日。
每篇字段：真实标题、全部作者、venue、year、DOI、arXiv、代码、数据集、方法、实验、消融、局限、证据位置、全文获取、审稿状态。检索命中不等于深读。

主协调要求gpt-6.1-sol/high，子代理gpt-6-luna/high；主聊天不能自行重设模型，CLI将显式传参。工作代理与审稿代理独立目录交接，主线程保留科学判断。并发通常两个工作代理和一个审稿代理；GPU任务严格串行。

当前未运行任何训练：new_fits=0、optimizer_steps=0。计划种子42/67/123，具体实验数/时长/磁盘预算在数据规模审计后、首次训练前写run_budget.json。不能把规划写成执行。
数据下载保留来源、许可、大小与SHA256，支持续传和去重；不可改动原始数据。
实验必须同时保存逐电芯逐查询预测、原单位MAE、配置、源代码/数据/拆分哈希、随机种子、日志、资源及失败原因。

TSC扩展只有在出现真实服务选择、编排、调度或资源分配问题，且有服务级目标、可重现实验及合理对照时才开发。若工作仅是寿命回归，可判定TSC适配不足；不强行加入服务模块。
