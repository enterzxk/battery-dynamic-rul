# 面向论文的快速执行路线（2026-10-18，V11根协调）
## 研究判断
主问题收敛为：单颗目标电池逐循环产生新观测时，如何判断退化信息并产生可靠的条件RUL分布。离线群体训练允许；单电池指预测对象，不等于仅用一颗电池训练。存活条件化是标准概率运算，不能单独当创新；稳健斜率也是强基线，不包装成新方法。优先验证信息增量与失效机制，避免先选Transformer/预训练/门控再找理由。

## 数据处理：只做会改变论文结论的工作，一次形成DataV1
1. 先从已存原始文件/下载清单定位，不重复下载。优先MATR原始实验批次，独立体系候选NASA；同源Toyota/MATR不同整理版不能算跨数据集验证。先核2颗代表性电池和导入规则，确认后一次性生成全量资产，不逐颗循环smoke。若完整原始MATR不可得，立即保留明确阻塞，评估官方NASA入口；不无限修旧v11生成链。
2. 原始→规范表仅保留physical/sourceID、实际cycle/time、容量Ah及可取得的I/V/T、工况、来源SHA；合并续测/别名必须有依据。物理ID不能证明时称source-record实验，不宣称物理独立。训练/开发/独立确认先按电池分组冻结，再生成前缀；工况批次留出单列。已有52/19保留为开发集。
3. 统一数据字典与事件定义：容量Ah、cycle非采样点；主端点名义有效容量80%首次实际越阈。无越阈是右删失，C为最后可确认有效周期；未标注中止原因记未知，不能直接假设随机删失。作者外推EOL、首循环归一化阈值仅可另列端点。越阈后的后续恢复不改变首次事件定义。若改为连续K次越阈，需另协议并处理确认延迟，不能偷换标签。
4. t时刻输入只来自已完成cycle<=t。保留原始回弹；异常值用单位/传感范围/完整性预设规则标记，不能用未来轨迹决定删除。禁止全寿命平滑、双向插值、按寿命百分比对齐、完整寿命最大容量归一化。短缺口只用过去填补并带缺失掩码/间隔；长缺口跳过该origin，分母和覆盖率可追溯。实际cycle号有缺口时斜率分母必须用实际cycle差，不能用行号。
5. 初期只用age、当前SOH、固定20cycle稳健速率及一项长窗趋势。窗口/异常阈值/缩放/校准只用train；长期趋势缺历史就掩码，不补未来。当前完整循环容量是实验室可测假设，不能称无需容量或仅I/V的BMS部署结果。
6. 每颗电池的全部可用origin先求平均，再电池等权；训练也限制长寿电池的重复前缀权重。保存每源SHA、拆分ID、端点/删失、每个origin可见截止点和排除原因。已存审计有效部分复用。最小验证仅2颗真实样本的手算端点与as-of索引/单位/隔离；通过即全量生成，不另造测试套件。

## 最短实验链
A 已完成：固定20cycle稳健速率对照，1CPUfit；复用F0-F3，未重复训练。
B 下一实际任务：原始数据可用性+2cell因果预处理，一次冻结DataV1和新独立确认划分。先定位已存文件，必要新下载另设明确源/字节/时长预算；PBT已耗尽IO票据不复用。此阶段不新增预测fit。
C DataV1通过后：在新训练/开发协议上一次跑最小基线组：冻结早期分布、仅存活、当前状态、OLS速率、稳健速率；共享拟合的臂不重复fit。删失存在时用对应生存似然训练（事件log f，删失log S），不能将最后观测寿命当真RUL。增加一个有代表性的非线性或序列概率基线，以免只击败线性弱基线；不列全家桶。先固定seed42；确定性模型不机械多seed。
D 唯一候选方法（待DataV1失败模式验证后冻结）：训练侧不确定性约束的多尺度退化状态更新。要分辨短时容量回弹与长期退化阶段；优先最小landmark/AFT或hazard实现，不先搭复杂深度框架。输入量与简单基线匹配；不使用验证真实误差做在线回滚。只对照最强基线、候选完整体、去可靠性项、去长程状态项；若没有可靠性机制生效证据就不写该创新。
E 明确继续/止损：候选在开发集相对最强基线Time-MAE至少下降5%，配对电池bootstrap方向支持，至少2/3电池改善，严重高估不增加超过1个百分点（此为下一协议待运行规则，不追溯改判已有pilot），并无明显校准代价，才进独立体系或预封存批次。未达则NO_GAIN，不用更多seed救结果。通过后仅随机模型补13/42/77；正式test只在方法及选择规则完全冻结、独立授权后一次开启。候选预算在数据冻结时逐臂登记，不预先开放新神经fit。

## 评价与论文交付
主指标是事件可观测子集的全可用时段、先电池内后电池间等权Time-MAE（cycle），同时明确该子集受事件选择影响。报告严重高估>100cycles、80%区间覆盖/宽度和100/300cycle Brier；与baseline同origin配对。删失电池不编造真实RUL误差，有限时域生存指标只有在删失权重/支持条件可辨识时使用；批次与删失完全混杂时不写“自然删失带来收益”。额外报告按退化阶段/工况的误差，而不是只挑有利时段。延迟更新和稀疏测量只选一个贴近实际的设置做验证。
最小稿件包：一张冻结队列/预处理表、一张同协议主结果表、一张跨电池配对结果、一张预测轨迹与两个失败窗口、一张必要消融表。方法/数据协议现在可写，结论及摘要等正式结果；现有16.76%不能当最终论文效果。目标是形成可提交的研究闭环，不承诺刊物或录用。
