# 延迟报告下的绝对事件年龄风险：固定区间 AFT 未通过

## 结论

固定区间 AFT 没有通过预定开发筛选，状态 **`NO_GAIN_FIXED_INTERVAL_RISK`**。四种方法在同一 555 个内部开发查询上使用同样的已到达容量前缀和工况信息；风险目标是“到查询后四周时潜在越阈是否已经发生”，其中允许该事件在查询前已发生但报告尚未送达。这个累计风险不能称为“已知电池仍健康时未来四周的条件失效概率”。

在 506 个可判定风险查询上，区间 AFT 的电芯等权 Brier 为 **0.1908**，强两点斜率参考为 **0.0348**。候选减参考为 **+0.1561**，按 12 个工况组重抽样、对三项比较校正后的 98.333% 区间为 **[+0.0189, +0.3927]**；5 个电芯改善、30 个恶化。另有 **49 个查询的风险结果无法根据检查区间或删失随访判定**，没有填成阴性。

| 方法 | 电芯等权 Brier | 记录事件目标的电芯等权中位预测 MAE，周 | 截至四周的 TP / FP / TN / FN | 漏掉全部记录事件前窗口的电芯 |
| --- | ---: | ---: | ---: | ---: |
| 区间事件 + 右删失 AFT | 0.1908 | 356.28 | 0 / 0 / 478 / 28 | 17 / 17 |
| 记录事件作精确值 + 右删失 AFT | 0.1894 | 347.81 | 0 / 0 / 478 / 28 | 17 / 17 |
| 仅成熟记录事件 HGB | 0.7818 | 23.37 | 28 / 478 / 0 / 0 | 0 / 17 |
| 两点斜率点参考 | 0.0348 | 3.24 | 24 / 7 / 471 / 4 | 0 / 17 |

HGB 的 Brier 更差，但它把全部可判定查询判为阳性；两个 AFT 则全部判为阴性。区间 AFT 相对 HGB 的 Brier 较低不能掩盖其漏掉全部 17 个电芯的记录事件前窗口。两点斜率的二元输出是点预测诱导的确定判断，并不意味着概率已经校准。

区间 AFT 相对**相同训练行和权重**、仅把已记录事件 `U` 当精确值的 AFT，Brier 差为 **+0.00143**，校正区间 **[+0.00014, +0.00323]**。这说明本次固定对照没有观察到区间标签带来的增益，不说明区间删失方法普遍无效。以首次记录越阈为事件目标的 356.28 周 MAE 是模型实际输出产生的误差，没有通过裁剪或替换隐藏；它也不是测得的连续物理失效时间。

## 关键支持范围限制

训练查询的电池年龄范围约为 **3.00—11.99 周**；全部 **555 / 555** 个内部保留查询的年龄都高于训练最大值，最高约 **86.97 周**。保留查询的可见检查次数也全部超过训练最大值；102 条检查间隔、234 条最近斜率超出相应训练范围。树模型对这类范围外查询的行为需要警惕，但这些统计只能指出支持不足，不能单独证明模型失败的因果原因。

这意味着本结果同时暴露了固定早期截止与后期动态预测之间的时间支持断层。后续应先设计按历史已到达结果逐期更新的严格时间方案，并在每个预测时刻核对训练标签是否已经成熟；不能在已看过的保留结果上挑选截止或调参来挽救本次固定配置。

## 审计与限制

训练使用 76 条成熟区间事件和 368 条右删失查询：两个 AFT 使用完全相同的训练行和电芯权重，HGB 仅使用成熟记录事件并以工况隔离的折外残差构造分布；斜率回退只由本次截止前已成熟的训练事件计算。正式实验共 6 次 CPU 拟合。独立复核重新构造了 **555 个**查询前缀、重算 **2,220 行**保存预测，核对折外残差、标签成熟、逐电芯指标与工况重抽样区间；全部通过。复核脚本第一次在执行前因语法错误未启动，修复后才签发复核票据并成功重算，未额外拟合。

结果仅涉及此前多次使用的开发工况；可观察记录事件来自 17 个电芯、6 个工况，风险 Brier 涉及 35 个电芯、12 个工况。区间作为潜在连续越阈范围依赖不可逆和测量可靠假设；删失可能信息性，14 天报告延迟为模拟，第 100 天截止回顾性选择。原项目 C3/C4 和 16 个封存确认工况均未读取，当前仍没有投稿级独立验证。
