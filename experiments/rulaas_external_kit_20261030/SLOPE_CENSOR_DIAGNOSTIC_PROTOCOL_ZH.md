# KIT 斜率参考与删失边界：固定预测回顾性诊断

问题：纯容量斜率在已观察记录越阈的电芯上误差较低时，是否会在尚未观察到越阈的电芯上，给出早于已知存活随访的时间？四周阈值判断的漏报和误报各有多少？

只读取已完成、已独立复核的第 100 天和阻抗开发实验保存的预测，复用同一 519 个 `(cell_id, query_epoch)`；7 个方法为纯斜率、原 HGB、共同检测时间 HGB、阻抗 HGB、精确事件 AFT、删失 AFT 和斜率锚定 AFT。核对每个方法的工况、标签和查询，并检查旧 HGB/斜率在两份记录中一致。没有新训练、模型调用、输入构造、种子搜索、重采样或原始电芯数据读取。

预先固定的描述量：

1. 观察到事件的查询：每电芯平均绝对误差后再对电芯等权平均；分别保留每电芯与工况的数量。
2. 右删失查询：比较预测中位数与 `last_observed - query`，分别报告全部删失查询、正随访查询及其电芯等权比例、受影响电芯/工况数和每电芯记录。正随访以最后一次测量仍未记录越阈为依据；零随访留在全部分母并单列，不视为真实寿命或可判定事件。
3. 四周可判定查询以预测中位寿命 `<=4` 周作为统一二元参考，报告 TP/FP/TN/FN、漏掉全部事件前四周查询的事件电芯数，以及阴性误报电芯数；18 个无法判定的查询单列，不填为阴性。纯斜率不提供概率，不计算其 Brier 或概率校准。
4. 记录斜率退化采用训练中位寿命的查询数量；不改变其既有回退、阈值或预测。

这是先前使用过的开发工况上的诊断，不是独立验证、因果成本评价或模型选择试验。预测中位数早于删失下界是观察到更长随访，**并不单独证明概率分布错误**：概率模型的中位数允许之后存活，且按删失状态选择的子群并非随机。删失可能与工况、失效和停测有关；不以删失下界冒充真实失效时间，不做显著性或总体覆盖声明。首次定期检查记录的越阈也不等于精确的连续物理失效时刻。

预算：固定输入哈希、0 次拟合、0 次模型预测、0 次 C3/C4、0 次 16 个封存确认工况读取；若键、标签、已发布结果或组隔离不一致，立即中止并保留失败记录。结果仅用于识别下一项值得独立设计的研究问题，不修复已判定 NO_GAIN 的模型配置。
