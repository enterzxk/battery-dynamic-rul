# KIT 固定趋势窗口对照：未超过两点斜率参考

## 结论

固定三点和五点趋势窗口均未通过预定开发筛选，状态 **`NO_GAIN_FIXED_TREND_WINDOW`**。在同一容量检测历史、同一 519 个查询、同一事件定义及回退下，仅改变用于估计当前退化速率的最近记录数，更多历史并未带来本次所要求的综合收益。

| 方法 | 已观察事件的电芯等权 MAE，周 | 与两点斜率的 MAE 差及 97.5% 配对工况区间，周 | 396 个正随访删失查询中过早预测 | 四周 TP / FP / TN / FN |
| --- | ---: | ---: | ---: | ---: |
| 最近两点斜率 | 2.79 | 参考 | 22 | 16 / 3 / 482 / 0 |
| 最近三点直线趋势 | 2.99 | +0.19，[-0.08, +0.41] | 23 | 16 / 3 / 482 / 0 |
| 最近五点直线趋势 | 3.57 | +0.78，[+0.21, +1.14] | 28 | 16 / 6 / 479 / 0 |

三点窗口在 16 个事件电芯中改善 4 个、恶化 12 个；五点窗口改善 2 个、恶化 14 个。五点窗口对已观察事件的平均误差增加约 28%，并且四周误报查询由 3 个增至 6 个。两个区间使用相同固定随机种子和 6 个事件工况为抽样单位，按两项比较进行校正；工况数少，不能将区间视作稳健的独立泛化证据。

此前被观察到过早预测集中的 P049 工况上，66 个有正随访的删失查询中，两点、三点和五点方法分别有 **18、19、23** 次预测早于最后一次仍未记录越阈的随访。P049 是根据先前结果识别的开发子组，仅用于解释，未被用于单独通过判定或调参。

## 公平性与验证

两个候选对每次查询分别使用最近 3 或 5 条截至当时的容量记录，按真实时间做普通最小二乘，当前容量仍用作外推起点；趋势非负时沿用两点参考已有的训练中位数回退。所有 519 个查询都有足够历史，三点和五点分别回退 4 次和 0 次。两点参考的 519 条保存结果也从当时的历史中重建并逐条核对。

独立复核使用另一种线性求解方式，重新从查询时已有的前缀计算 **1038 条候选结果**，并重算逐电芯误差、四周混淆矩阵及配对工况区间，结果均通过。本次正式比较进行了 1038 次局部直线估计，无新增全局模型训练；复核中另有 1038 次用于重算的局部估计。原项目 C3/C4 和另外 16 个封存确认工况均未读取。

519 条查询包括 105 条后来观察到记录越阈和 414 条删失；18 条四周结果未知，未计为阴性。对概率模型而言，预测中位数早于删失下界本身不证明校准错误；此处三个方法都是点预测，统计的是外推时间早于已知仍未记录越阈的随访。首次定期检查记录的越阈也不是连续物理故障时刻。

这些方法都采用已测容量的即时可见假设，实际报告送达时间未知；离线筛出的越阈前查询不能直接当作前瞻服务到达。先前已使用开发结局、训练截止时点经过回顾性选择，事件仅来自 6 个工况；结果不代表独立验证，且不能说明所有趋势平滑方法都无效。

下一步保留两点斜率作为强参考，停止固定三点和五点配置；应将真正可用的信息、检测间隔和资源约束与失效风险联合检验，只有在相同查询和检测资源下同时获得可重复的安全与成本收益，才考虑作为论文服务机制。
