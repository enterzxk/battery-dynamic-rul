# P2 误差结构诊断 + 尾部探针（2026-10-27）

**结论：强基线 RUL 的误差不是弥散的，而是由"长寿命电芯系统性低估"主导。
按预注册规则做的斜率外推探针：显著改善 32+ 周桶（11.46→9.08 周）但损害 12–32 周桶（3.71→4.89 周），
总体 +0.317 周（CI [−0.107, +0.754]）→ 该配置 NO_GAIN，停止。下一步机制必须在训练 OOF 上选阈值，而不是在 C3 上调。**

## 1. 诊断证据（0 拟合，只读 saved predictions/targets/rows）

- 数据：C3 开发集，2,697 条正寿命计分键、60 个电芯、三个报告臂。
- **|误差| 与目标 RUL 的相关系数 = 0.853**；与历史长度 0.097、与循环计数 0.202 → 误差几乎完全由"还剩多久"决定。
- 误差分解（中位数预测，电芯等权）：

| 目标桶 | 查询 | 电芯 | 中位 MAE | 偏差 | 占总绝对误差 | 严重>4周 | 桶内目标中位 |
|---|---|---|---|---|---|---|---|
| 0–4 周 | 528 | 60 | 0.706 | +0.172 | 3.4% | 0.6% | 2.3 |
| 4–12 周 | 1,029 | 59 | 1.916 | −0.037 | 17.6% | 12.5% | 8.0 |
| 12–32 周 | 879 | 36 | 3.711 | −1.931 | 37.4% | 46.3% | 18.4 |
| **32+ 周** | **261** | **7** | **11.464** | **−11.462** | **41.5%** | **91.2%** | **45.7** |

- 最差电芯：G26C3（MAE 17.19，偏差 −17.18，n=168）、G1C3（10.69/−10.63）、G6C3（10.06/−10.03）、
  G18C3（6.77/+6.77）、G7C3（6.37/−6.28）——前三个是长寿命电芯，被**系统性低估 10–17 周**。
- 三个臂的误差几乎相同（raw 2.290 / sparse2 2.455 / delay7d 2.571），说明**延迟/稀疏不是主因**；
  历史长度在控制目标后也只剩小效应。
- 现有全部方法在同一尾桶都失败：F3 32+ MAE 11.46（偏差 −11.46）、P1 直接平方 10.88（−10.85）、
  P3 线性校准 12.24（−12.24）——**校准反而放大尾部偏差**。这不是"再校准一次"能解决的问题。

## 2. 预注册尾部探针（0 拟合）

规则（先写死，未在 C3 上调参）：
- r = last_capacity_over_nominal（F0[1]），s = recent_theilsen_slope_over_nominal_per_week（F0[8]），
  退化速率取 |s|；穿越时间 = clip((r − 0.80)/|s|, 0, 128) 周（0.20 Ah / 0.25 Ah 标称 = 0.80 比例阈值）。
- TREE = hgb_F3 中位数；M1 = TREE 若 TREE≤12 周，否则 (TREE+穿越时间)/2；EXTRAP = 只用穿越时间（消融）。

输入体检：ratio 中位 0.994（p05 0.841 / p95 1.092），slope 中位 −0.0108/周（99.9% 为负），
穿越时间中位 16.4 周，全部有限 → 规则可执行。

结果（raw/unconfirmed，2,697 键 / 60 电芯）：

| 方法 | 全体 | 0–4 | 4–12 | 12–32 | 32+ |
|---|---|---|---|---|---|
| TREE | 2.439 | 0.706 | 1.916 | 3.711 | 11.464 |
| EXTRAP | 7.858 | 3.475 | 7.923 | 9.374 | 15.847 |
| M1（>12 周混合） | 2.755 | 0.706 | 2.113 | 4.891 | **9.081** |

配对（60 电芯，5,000 次）：M1 − TREE 全体 **+0.317 周 [−0.107, +0.754]**；
y>12 子集 +0.933 [−0.236, +2.120]；EXTRAP − TREE 全体 +5.606 [+3.651, +7.710]。

**判定：NO_GAIN。** 斜率外推只在最极端尾部（32+）有信息，但同一规则伤害 12–32 段，
净效应为零且区间跨 0。保留该证据，不通过改阈值/改端点来"救"结果。

## 3. 由证据确定的下一机制（下轮执行，需新 GO）

**M2：训练 OOF 选择的尾部切换（tail switch），而不是 C3 上的阈值。**

- 假设：长寿命电芯的容量轨迹近似线性且斜率可估；对"预测 RUL 很长且轨迹近似线性"的子群，
  用轨迹穿越时间替代/混合树的中心收缩，可以降低 32+ 桶误差而不伤害 12–32。
- 关键：**切换阈值与混合方式在训练电芯 OOF 上选择并冻结**（使用已保存的 hgb_F3_oof0/1 预测与训练残差；
  不接触 C3 标签做选择），C3 只做最终评分。这直接避免本轮探针在 C3 上隐含调参的问题。
- 必要对照：TREE（原 F3 中位数）、EXTRAP-only、固定阈值 M1（本轮已测）、OOF-选择切换。
- 关键消融：去掉斜率项（只用时间趋势）、去掉线性假设（用最近 k 点）。
- 主指标：raw/unconfirmed 电芯等权中位 MAE，**同时要求 32+ 桶改善且 12–32 桶不恶化**；
  配对 CI 不含 0 才算通过。预算：0 新拟合（只用 OOF 残差与现有特征）；若需小树，≤2 CPU fits。
- 若 M2 仍 NO_GAIN：结论是"在现有 710 维 as-of 特征与直接监督范式下，长寿命尾部不可由轨迹外推修复"，
  据此转向论文的诚实边界（信息价值 + 失败结构），而不是继续加模型。

## 4. 限制

- C3 是开发集（多轮适应性选择），不是独立确认；本诊断不构成确认证据。
- 32+ 桶只有 7 个电芯、261 条查询，统计力有限；任何尾部机制都必须报逐电芯伤害。
- 标称 0.25 Ah 与 0.80 比例阈值是项目既定口径；跨体系（CALCE 1.1 Ah）不可沿用。
- 本轮 0 C4；CALCE RUL 标签门保持。
