# P3 训练折外条件残差校准：固定开发检验（2026-10-27）

问题：旧 F3 的训练电芯折外 log-RUL 误差与退化速度有关。低容量条件校准能否改善独立开发电芯，而不强加上轮已失败的健康时间尺度？这是强基线诊断，不预设新颖性。

基础模型、训练人口、事件概率均保持：原正式F3，正寿命训练查询4713条，C1/C2训练、C3开发。旧2折模型复算每个训练查询的折外 log 预测mu和残差r=log(y)-mu，逐位匹配原保存残差。C3不拟合任何参数。

校准以电芯等权残差平方损失拟合以下三个固定模型，合计最多3次CPU校准拟合；不训练基础预测器，不搜索：

- `ridge_context`：Ridge(alpha=10)，输入mu和F3列[0,1,3,4,6,8,686,687]，9维；标准化均值/方差仅用训练数据电芯等权估计。
- `hgb_context`：相同9维输入，HGB 50 iterations、4 leaves、depth2、min_samples_leaf50、L2=10、seed42、关闭早停。
- `hgb_mu_only`：仅用mu，同一HGB容量；隔离额外可见健康/报告信息的校准价值。

分布使用同一旧OOF经验残差形状，条件模型只替换其位置：log支持=mu_dev + g(context_dev) + r_saved - weighted_mean(r_saved)。当前隐藏失效概率固定为旧F3同键输出，已确认失效归零。没有用校准模型的拟合残差估计新的不确定性。

全局控制令g=weighted_mean(r_saved)，必须逐查询重现旧F3的分布均值、中位数和时窗概率（容差1e-9）。校准收益不得来自偷偷更换事件模型、噪声分布或标签。

主分析保持raw/unconfirmed、候选中位数对旧F3中位数，完整辅报同键均值、all/hidden_event/early/near、三臂、区间与概率评分和逐电芯伤害。条件模型还必须面对mu-only控制。按物理电芯配对bootstrap5000次；多项探索不称独立确认。

最大运行600秒；最多3次校准fits、0基础模型fits、0神经训练、0C4。未知事件寿命不补值；固定源RPT阈值0.20Ah的剩余周数。候选无收益则记录NO_GAIN并停止，不改alpha/容量或追加seed救结果。

若有收益，仍须检验OOF基础模型训练规模与最终全训练模型的差异、机制消融、近邻方法、外部多电芯RUL验证，不能直接升级为论文创新或确认。
