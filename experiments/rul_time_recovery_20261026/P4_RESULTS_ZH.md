# P4：直接 RUL 监督的历史信息检验（结果，2026-10-27）

**结论：NO_GAIN。静态 710 维 F3 快照没有丢失可用的历史信息；完整历史既不改善 RUL，
在 GRU 上反而更差。GRU 直接监督 RUL 在本预算下远劣于树。停止该配置，不扩网络/加种子。**

## 3. 解释（与 P1–P3 一致的证据链）

1. **历史没有增量**：HGB 加固定完整历史摘要后比原 F3 **更差**（+0.124 周，CI 含 0），且显著差于 P3 线性校准
   （+0.226 [+0.053, +0.438]）。这与“F3 的曲线、首末差分与过去斜率已充分压缩历史”的解释一致。
2. **GRU 直接 RUL 监督在本预算下失败**：7.1–7.7 周，且 history 比 current **更差**（+0.6 周）——
   在 400 步选择/400 步 refit、64k 参数、batch 32 的预算内，序列模型没有超过树；这与 P1/P2/P3 的 NO_GAIN 同向。
3. **概率质量也差**：GRU cov80 0.21–0.30（严重过窄），HGB 0.882 与 F3 相同；没有“概率更好”的补偿性收益。
4. 因此 P4 的唯一假设被否定：**完整历史信息已被静态 F3 摘要充分表达**（在这套特征与预算下）。

## 4. 必须同页的限制

- 这是 **C3 开发集**、单 seed（42）、单内部划分；C3 已多轮开发，不是独立确认。
- GRU 的 400+400 步是**预注册预算**，不是“已调到最优”。结论只能限定为“该预算下无增量”；
  按计划，不得用扩网络/加种子来救结果。
- HGB 历史摘要是一张**训练前固定**的 769 维摘要表（前缀均值 + 8 个基列的 7 个统计 + 3 个时间量），
  不是穷举历史；更强摘要不在本阶段预算内。
- 本轮 **0 C4**；C4 既有容量曝光（10-25）继续披露；CALCE RUL 标签门保持。
- 三个失败 GO 的失败回执保留（GPU 被占用一次、device bug 两次），不作为结果。
