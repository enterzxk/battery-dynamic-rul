# M2：训练 OOF 选择的尾部切换（2026-10-27）

**结论：NO_GAIN，且方法学上更重要的结论是——训练 OOF 把切换阈值推到网格边缘（τ*=40），
等价于"不要用斜率外推"。上一轮在 C3 上看到的 32+ 桶改善（τ=12）是 C3 特定效应，不能从训练数据复现，
因此不可作为机制证据。停止尾部外推方向。**

## 1. 协议（0 拟合）

- 规则族（先固定）：tree = exp(log-RUL 预测)；cross = clip((ratio−0.80)/|slope_ratio_per_week|, 0, 128)；
  R(τ) = tree 若 tree ≤ τ，否则 (tree+cross)/2（cross 非有限时回退 tree）。
- **选择**：在训练电芯 OOF（hgb_F3_oof0/1，4,713 条正寿命训练行，cell 两折划分 seed 42）上，
  网格 τ ∈ {8,12,16,20,24,28,32,36,40}，取 cell-macro MAE 最小者；C3 只在冻结后评分一次。
- 对照：tree-only、τ=12 固定规则（上一轮 M1）、EXTRAP-only、M2(τ*)。
- 数据：训练/开发特征缓存 + 已保存 F3 joblib（仅推理）、C3 saved predictions（敏感性对照）。0 拟合、0 C4。

## 3. 解释

1. **C3 上的尾部改善不可复现**：τ=12 时 32+ 桶确实从 11.92 降到 9.17，但同一规则在训练 OOF 上更差
   （OOF 在 τ=12 时 2.888，在 τ=40 时 2.480）→ 该改善是 C3 特定（7 个长寿命电芯）效应，不是可迁移机制。
2. OOF 选择把 τ 推到边缘，说明**训练数据不支持"用斜率外推修补长寿命低估"**；M2 的 −0.015 周
   （CI [−0.046, 0]）在实质上等于"与原树相同"，不构成收益。
3. 与前几轮一致：F3/P1/P3/M2 都在 32+ 桶系统性低估 ~11 周；在现有 710 维 as-of 特征与直接监督范式下，
   轨迹外推不是修复该尾部的正确机制。

## 4. 判定与下一步

- M2 **NO_GAIN**：不部署、不扩种子、不换指标。尾部外推方向到此关闭，保留为负结果。
- 论文含义（诚实）：最强的直接 RUL 监督在短/中视界已很好（0–4 周 0.71、4–12 周 1.92 周），
  其失败结构集中在**极少长寿命电芯的尾部系统性低估**；这不是"再校准/再外推"能解决的，
  需要**新的信息源**（例如同组/跨体系的寿命先验、真实检查计划、或更长的观测窗口），而不是更多模型容量。
- 下一步候选（需新 GO，且必须先解决信息源而非模型）：在训练数据中寻找对长寿命可辨识的信息
  （例如早期库仑效率/温度/工况组），或明确把 32+ 尾部作为"预测下界 + 明确不确定"的诚实输出，
  并在论文中把它写成失败边界，而不是假装已解决。
