# 固定34电池的误差贡献分解

结论：两只作者寿命超出训练范围的电池主导绝对误差，但不主导Ridge速率增益；即使单独查看训练寿命范围内32电池，速率增益仍不足预设推进幅度。原主指标、人口、标签和NO_GAIN保留，不删除离群电池或以子群替换主结果。

训练作者EOL范围147..1834，固定验证34电池/136时点；分组仅事后解释，绝不用于筛选训练、评估origin或模型输入。范围内指目标标签范围，不等于输入分布或在线资格。

两只超出训练寿命范围的电池：MATR_b1c2、MATR_b3c38。它们贡献A1全体绝对误差43.676%，却只贡献Ridge A1→A2净误差下降的11.662%；其余32只贡献88.338%。所以不能说小速率收益仅由两只离群电池驱动，也不能通过删掉它们将结果包装为成功。
