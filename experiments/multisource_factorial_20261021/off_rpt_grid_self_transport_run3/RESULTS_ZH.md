# Off-RPT 网格上的同模型运输与信息增量：结果

## 结论

在 C3 开发集的日历 3.5 天网格上，加入 Cycling 特征后的 F2/F3 在大多数 arm、模型下比 F0/F1 有更低平均 RUL 误差和 IS80；但直接比较 F0(a)→F2(b) 或 F1(a)→F3(b) 会把真实时间流逝与期间到达的 Cycling 信息混在一起。用相同模型做自运输并做匹配差中差后，F3 相对 F1 的增量改善小且多数区间跨 0；F2 相对 F0 的 RUL MAE 差中差在 HGB 三个 arm、CatBoost sparse2/delay7d 为负且 95% cell-bootstrap 区间不跨 0。结果支持“cycle-only 信息在此离线条件下有一定增量”，不支持把旧跨 panel 结果整体归因于新 Cycling 信息，也不是独立确认。

## 设计与范围

- 输出为 off-RPT 评估；沿每个 C3 cell 的第二个有效 RPT stop 后 7 天起，以 302,400 秒（3.5 天）步进，至 source window 最后有效 RPT stop；剔除距真实 RPT stop 1 秒内的网格点。固定事件时间 T；同一 `(cell, arm, history_key, query_a, query_b)` 做匹配比较。
- 实际覆盖 63 个 C3 source cell；其中 61 个有共同 off-grid query，2918 个同步时间点 / arm，三 arm 共 8754 个例子。每个 arm 汇总 2918 行、61 个 query cells。连续 outcome 的匹配 bootstrap 为 60 个 cell（60 而不是 61 是有效连续成对 outcome 的实际支持数）；event Brier 为 61 个 cell。未预设 cell 数来筛数据。
- 复用原正式 80-fit 的 8 个已存模型，0 次新 fit、0 optimizer step；推理 70,032 行，耗时 1083.1 秒（约 18.1 分钟，主要为 as-of feature index/grid 构建与推理）。不读取 C4。
- 读入的是受 manifest/hash pin 约束的 C3 processed DataV2 数据，以及相同 188-cell manifest 产生并按运行 receipt 校验的派生 RPT/Cycling 特征文件；原始 RPT/Cycling archive / `.raw_members` 读取数为 0，C4 payload 读取数为 0。原 GO 的 `allow_raw_data:false` 针对原始 archive；本次读取 processed/derived 层是该 GO 已审查批准的范围。这是 I/O 范围澄清，不更改 GO 或运行 receipt。
- 来自实验假设：cycle arrival time unobserved，按 source completion time 视为可用；这不是已观测的在线到达延迟。

## Same-model transport 与差中差

定义：同一 panel 的 `self_transport` 把在 a 的模型/输入随时间推进到 b，并和在 b 按该 panel 可见输入重算的输出配对；`DID_F3_minus_F1_selfupdate` 比较 F3 与 F1 的 source-update 相对 time-only transport 的变化，`DID_F2_minus_F0_selfupdate` 同理比较 F2 与 F0。表中为 source-update − time-shifted 的物理 cell 配对均值；负值偏向 source update。区间按物理 cell bootstrap 95% CI，查询时点不是独立抽样单位。

### 自运输本身：F3 的 source update 相对时间平移

这一对照检查“同一个已训练 panel”是否因在 b 获得更多有效输入而优于只将 a 的分布按时间平移。下表仍为 source-update − time-shifted，负值偏向实际输入更新；这里 Cycle 的到达时刻仍依赖上述 source-completion 假设。

这些自运输多数 MAE 与 Brier 区间覆盖 0：更强的 F3 绝对表现主要不能被解读成每个 no-new-report 间隔都有稳定的在线更新收益。另一个关键限制是 raw arm 上“当前阈值事件是否已发生”可由真实 source RPT event 直接观察；其接近零的 event Brier 属结构性已知信息，不代表模型从不确定状态更新中获得机制性改进。更有信息量的是未来 4/12 周风险和连续 RUL，但其 DID 增量有限且模型/arm 有异质性。
