# 动态电池 RUL：服务收益实验计划（2026-10-29）
用户已明确授权开启目标模式，并持续推进到具备论文竞争力的证据。本计划记录研究目标转向，原 P1–P4 的 NO_GAIN/弱信号不改写。

## 完成目标的判据
1. 因果有效的数据与决策时序：物理电芯隔离、固定参考事件、明确删失及支持窗口；在线控制不得读取尚未到达的寿命真值。
2. 至少一个有明确近邻差异、能被消融检验的机制，在同信息、同资源、同动作支持下可靠超过强调度对照。只打败随机/固定周期或只减少云调用不够。
3. 冻结主终点和可接受的质量差值，再确认有实质成本收益；非劣必须用相应区间上界检验，不能用“差异不显著”。
4. 多电芯、必要场景与独立确认支持结论，保留不利电芯、失效与删失记录；C3 多轮开发不能充作独立确认。数据门不因长期授权自动解除。
5. 可复现代码、预测、预算、失败回执，以及与核心文献定义/算法的差异和适用边界可供审查。是否录用由审稿决定，不作承诺。

## 第一条真实有界动作：固定 HGB 的检测信息价值实验
目录 experiments/rulaas_value_gate_20261029。只读取允许的 C3 DataV2、RPT/Cycling 已审核缓存及已训练 F3 HGB，0 新拟合、0 优化步、0 C4 payload。
seed=42，最多63来源电芯、30000行预测。全部策略保留相同前三次 RPT 作为初始化，固定每3.5天查询，查询从第三次 RPT 后7天至来源窗口结束。保留所有廉价循环特征，含现有容量代理。

预先固定6个策略：
- all0：全部RPT，来源结束即可见；
- all7：全部RPT，报告延迟7天；
- half_even7 / half_odd7：初始三次之后，按机会序号奇偶保留一半；
- half_hash7：每两个机会预先由 cell/block/seed 哈希选择一个，决策不读取未来数量或检测值；
- anchor7：仅前三次初始化，其后无新专门检测信息。

第一关只检验“额外RPT是否仍有边际预测价值，以及简单信息删减的损失”。不是共享车队排队实验，不称已经节省真实物理检测成本，不称已实现任何SLO。机会保留数量只是统一信息访问成本代理，初始检测成本单列。

主口径：固定查询集中参考RUL>0的查询，分布均值点预测的电芯等权MAE；不按策略是否确认失效删查询。辅助：全来源事件评分、80%区间/IS80、4周Brier与固定0.5阈值事件报警。未成熟视界与删失记录保留。
配对电芯bootstrap5000次；anchor7−all7 的区间下界>0才支持本内核上的额外检测信息价值。0.10周仅为后续删减可行性的开发筛选界，无外部业务依据，不是论文非劣承诺。奇偶两个相位全部报告，不在C3挑相位冒充新算法。
运行中用一条旧查询核对原F3向量；再做一条未到达RPT数值扰动不影响当前输入的检查。通过后直接评分，不新增重复测试。

## 下一阶段与停止规则
额外检测有可靠价值，才实现按现有检测机会进行的共享分析站排队回放。明确先取样/后处理排队的含义；不声称可在任意时刻真实补做诊断。
先比较调好的周期、年龄/不确定性、即时VoI及按实际到达时刻计算收益的VoI。固定外部轨迹、参考事件、资源，策略历史随选择变化。反馈控制只使用已成熟标签，边云路由待真实成本证据后再决定。
若第一关未支持信息价值，先从已保存逐电芯结果检验廉价输入冗余、时间段和数据支持；不盲目训练复杂调度。若机制失败则记录NO_GAIN并停止该配置，选择证据支持的不同问题。
每轮新实验使用新哈希预算与一次性GO；不复用消费GO、不扩网络/种子挽救、不改EOL或放宽服务约束，不因运行时间长自动判定成功。
