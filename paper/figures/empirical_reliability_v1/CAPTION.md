# Fig. 1 | Average gains do not establish individual RUL reliability

**a**, Paired per-cell mean absolute errors for four point predictors. Each grey line joins the same source cell across methods; points show individual cell estimates, not seed averages. **b**, Per-cell empirical coverage of nominal 80% intervals from the early-survival, dynamic and equal-CDF reference distributions. The dotted line marks 80%; no interval is assigned to the deterministic linear predictor. **c,d**, Complete observed and predicted RUL trajectories for b2c1 (48 origins) and b4c7 (430 origins), respectively. These explanatory cases were fixed before figure generation from prior development reports: b2c1 is an exception where the linear baseline performs well, whereas b4c7 retains substantial overestimation. All positive predictions, including sub-cycle values and very large linear extrapolations, are retained. Panels a, c and d use explicitly labelled logarithmic vertical axes; c and d have different ranges. No smoothing or favourable-window selection is applied.

The experiment uses 42 fitting source IDs and 10 repeatedly exposed development/calibration source IDs (4,567 total evaluation origins), with fixed seed 42 for learned predictors. Coverage uses an inherited reference scale, not an independently calibrated new model. Each cell contributes one estimate to panels a and b; within-cell origins are temporally dependent. No new significance test, uncertainty across seeds, independent-confirmation result or physical-serial independence is claimed. Source CSVs, immutable input hashes and rendered QA receipts accompany the figure.
